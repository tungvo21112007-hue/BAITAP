Giới thiệu

Ngành CNTT là lĩnh vực đào tạo về máy tính, phần mềm, mạng máy tính và hệ thống thông tin, giúp sinh viên có khả năng thiết kế, phát triển và quản trị các giải pháp công nghệ phục vụ đời sống và doanh nghiệp.

Cơ hội nghề nghiệp

Sinh viên tốt nghiệp có thể làm việc ở nhiều vị trí như lập trình viên, kỹ sư phần mềm, quản trị hệ thống hoặc chuyên viên phân tích dữ liệu. Theo Giáo trình Thiết kế web, nhu cầu nhân lực ngành này vẫn đang tăng trưởng mạnh trong những năm gần đây.

    <title>Tiêu đề trang</title>
</head>

    Nội dung trang web
</body>
</html>

Mục lục

HTML | CSS | JavaScript | Contact

HTML

HTML (HyperText Markup Language) là ngôn ngữ đánh dấu dùng để xây dựng cấu trúc cho một trang web.

Các phần tử HTML được biểu diễn bằng thẻ, ví dụ như <p>, <h1>, <div>...

HTML thường được kết hợp với CSS để định dạng giao diện và JavaScript để xử lý tương tác.

CSS

CSS (Cascading Style Sheets) là ngôn ngữ dùng để mô tả cách hiển thị của các phần tử HTML trên trang.

CSS cho phép tùy chỉnh màu sắc, khoảng cách, bố cục, font chữ và nhiều thuộc tính hiển thị khác.

CSS có thể được viết trong thẻ <style>, dùng thuộc tính style hoặc đặt trong một file riêng.

JavaScript

JavaScript là ngôn ngữ lập trình giúp trang web trở nên tương tác và sinh động hơn.

JavaScript có thể thay đổi nội dung, xử lý sự kiện của người dùng và giao tiếp với máy chủ.

JavaScript chạy trực tiếp trên trình duyệt và thường được kết hợp chặt chẽ với HTML, CSS.

Front-end
Front-end là phần giao diện người dùng nhìn thấy và tương tác trực tiếp trên trình duyệt, thường được xây dựng bằng HTML, CSS và JavaScript. Tham khảo tại MDN Web Docs.

Back-end là phần xử lý phía máy chủ, chịu trách nhiệm về logic nghiệp vụ, cơ sở dữ liệu và giao tiếp với front-end thông qua API. Tham khảo tại roadmap.sh.
